## Main Lessons on Clean Code
- If the same code is written multiple times, make a function or module instead.
- Write meaningful and consistent names (e.g. variables, functions, and classes) following the naming conventions.
- Write meaningful comments to explain what the code does (when code is complicated).
- Use exception handling instead of letting the program crash.
- Make sure the functions follow the single responsibility principle (SRP).
